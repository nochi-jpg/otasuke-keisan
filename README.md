# おたすけ計算

ひっ算より 前の たし算・ひき算（20までの 数）を、ブロック・数の線・さくらんぼで 考える HTML アプリ。答えは 出さずに、キャラクターが 1手ずつ 案内する。「ひっ算おたすけ君」から 派生。

## つかいかた
- GitHub：https://nochi-jpg.github.io/otasuke-keisan/ （`index.html`）
- Canva：`dist/otasuke-keisan-canva.html`（`python3 tools/build.py` で つくる）
- 元のファイル：`src/`（`index.html`・`style.css`・`logic.js`・`app.js`・`assets/`）
- `src/` を 直したら かならず `python3 tools/build.py` を 実行

## しよう（決まったこと）
- くわしくは `docs/SPEC.md`、理念は `docs/PHILOSOPHY.md`
- はじめに えらぶ
  - 問題おたすけモード：子どもが 式を 入れる
  - 問題挑戦モード：くりあがり なし／あり の たし算、くりさがり なし／あり の ひき算 から えらんで 10問（ランダム）。最後に「10点まんてん中 □点」
  - おたすけレベル：たくさん（ブロック・数の線・さくらんぼで 一手ずつ）／すこし（こまったら アシスト）／なし（まちがえたら アシスト）
- 図は ブロック・数の線・さくらんぼを 上の ボタンで 切りかえ（スクロールなし）
- せってい：たし算で わける数（うしろ／まえ）、ひき算の やりかた（10から ひく＝減加法／ひく数を わける＝減減法）、効果音
- 点数：最後の 答えが 合えば 1点。「すすむ」で 最後の 答えを 見たら 0点
- 5mm方眼ノート（18列×12行）、1マス1文字。セーブなし

## テスト
