# おたすけ計算　仕様

ひっ算おたすけ君から 派生した、筆算より 前の たし算・ひき算の 学習支援アプリ。
理念は `docs/PHILOSOPHY.md` を そのまま 引きつぐ（考えるのは子ども・答えは出さず次の一手だけ・小さな支援を重ねる）。

## 1. 対象
- 小学1〜2年（数の認識が 苦手な子も ふくむ）
- 99までの 数どうしの たし算・ひき算（99＋99 まで。答えは 198 まで）
  - 20まで：1年の やりかた（ブロックを うごかす・10を つくる）
  - 20より 大きい：2年の あんざんの やりかた（10の ぼうと ばら）

## 2. 画面の流れ
1. タイトル → モードを えらぶ
   - **問題おたすけモード**：子どもが 式を 入れる
   - **問題挑戦モード**：アプリが 出す 問題に 挑戦する
2. （挑戦モードのみ）数の 大きさを えらぶ：20までの 数／99までの 数
3. （挑戦モードのみ）問題の しゅるいを えらぶ
   - くりあがりなし たし算／くりあがりあり たし算／くりさがりなし ひき算／くりさがりあり ひき算
4. おたすけレベルを えらぶ：たくさん／すこし／なし
5. 問題を とく
6. （挑戦モードのみ）10問 おわったら「10点まんてん中 □点」と 花丸・紙ふぶき

## 3. 問題の はんい
| しゅるい | はんい | 例 |
|---|---|---|
| くりあがりなし たし算 | 答えが 10まで、または 10＋□・1□＋□（くりあがらない） | 3＋4、10＋5、12＋3 |
| くりあがりあり たし算 | 1けた＋1けたで 答えが 11〜18 | 8＋5、9＋7 |
| くりさがりなし ひき算 | 10までの ひき算、または 1□－□（くりさがらない）・1□－10 | 7－3、15－2、14－10 |
| くりさがりあり ひき算 | 11〜18 から 1けたを ひいて くりさがる | 13－9、12－5 |

- 99までの 数：上の はんいに 入らない 式（20より 大きい 数を つかう 式）。くりあがり・くりさがりは 一の位で きめる（例：38＋25＝あり、32＋25＝なし、63−25＝あり）
- 挑戦モード：えらんだ 大きさ・しゅるいの 式を ぜんぶ 用意して、そこから ランダムに 10問（同じ式は 出さない）
- おたすけモード：99までの 数なら どの 式でも 入れられる（100いじょうは「99までの 数で やろう」）

## 4. 見せ方（3つを 上の ボタンで 切りかえ・スクロールなし）
- **ブロック**：10の マス（5こずつ 2列）を 2つ ならべる。たす数・ひく数は 色を かえる
- **数の線**：0〜20。10の ところを 強く 光らせる。とぶ 矢印で たし・ひきを 見せる
- 99までの 数では：ブロックは 10の ぼう（ばら10こ）と ばら、数の線は 0〜100（答えが 100を こえるときは 0〜200）
- さくらんぼを つかわない 問題（3＋4・7−3・30＋40 など）は、さくらんぼボタンを けす
- **さくらんぼ**：方眼ノートに 式と さくらんぼを 書く（1マス1文字）

## 5. 考える 手順（おたすけレベル たくさん の とき）
### たし算（くりあがり あり）　例：8＋5
1. 「8は あと いくつで 10？」→ 2（ブロックで 空いた マスを 光らせる）
2. 「5を 2と いくつに わける？」→ 3（さくらんぼを 書く）
3. 「8＋2＝？」→ 10
4. 「10＋3＝？」→ 13
- せってい「前の数を わける」のときは、前の数を わけて 後ろの数を 10に する（例：3＋9 → 3を 1と2に わけ、9＋1＝10、10＋2＝12）

### ひき算（くりさがり あり）　例：13－9
- **減加法**（はじめの せってい）
  1. 「13を 10と いくつに わける？」→ 3
  2. 「10－9＝？」→ 1
  3. 「1＋3＝？」→ 4
- **減減法**（せっていで 切りかえ）
  1. 「9を 3と いくつに わける？」→ 6
  2. 「13－3＝？」→ 10
  3. 「10－6＝？」→ 4

### 99までの 数（せってい「2けたの けいさん」で 切りかえ）
- **10と ばらに わける**（はじめの せってい）：38＋25 → 38を 30と 8、25を 20と 5 → 30＋20＝50、8＋5＝13、50＋13＝63
  - ひき算で ばらから ひけないとき：63−25 → 63を 50と 13、25を 20と 5 → 50−20＝30、13−5＝8、30＋8＝38
- **なんじゅうを つくる**（くりあがり・くりさがりの ときだけ。それ以外は「10と ばら」）：38＋25 → 25を 2と 23 → 38＋2＝40、40＋23＝63／63−25 → 25を 3と 22 → 63−3＝60、60−22＝38
- さいごの 式の 答えは、上の 式へ じどうで とばす（同じ 数を 2回 書かせない）
- ブロックは 見るだけ（うごかさない）。いま つかう ぼう・ばらを 蛍光ペンで 光らせ、ひいた ぶんは ななめ線で けす

### くりあがり・くりさがり なし（20まで）
- たし算：ブロックを あわせて「ぜんぶで いくつ？」
- ひき算：ブロックを とって「のこりは いくつ？」
- 10＋□・1□±□は「10の まとまりと ばら」に 分けて 考える

## 6. おたすけレベル
| レベル | 中身 |
|---|---|
| たくさん | ブロックと さくらんぼを、一手ずつ 案内する |
| すこし | 式だけ 出す。まちがえたとき・「アシストを みる？」を 押したときに さくらんぼを 出す |
| なし | 答えだけ 入れる。ヒントは 出さない。ただし まちがえたら さくらんぼを 出す |

## 7. 子どもの 操作
- ブロック：タップで 動かす（10の マスへ うつす・とる）
- 数字：テンキーで 書く

## 8. 点数（挑戦モード）
- 最後の 答えが 合えば 1点（とちゅうで まちがえても よい）
- 「すすむ」で 答えを 見た 問題は 0点
- 10問 おわったら「10点まんてん中 □点」。もういちど／しゅるいを かえる／タイトルへ

## 9. せってい
- さくらんぼで わける数：後ろの数（はじめ）／前の数
- ひき算の やり方：減加法（はじめ）／減減法
- 2けたの けいさん：10と ばらに わける（はじめ）／なんじゅうを つくる
- 効果音：あり／なし
