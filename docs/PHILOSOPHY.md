# おたすけシリーズ　アプリの作成理念

「ひっ算おたすけ君」（整数版・小数点あり版）で大事にしたことのまとめです。
このアプリから派生させるアプリ（筆算より前のたし算・かけ算、面積、分数など）も、この理念を土台にします。

---

## 1. いちばん大事なこと：考えるのは子ども

- **答えは出さない。出すのは「次の一手」だけ。**
  キャラクターが「つぎは 十の位。5と8と、くりあがりの1を たそう」のように、今やることを1つだけ言います。
- **書くのは子ども。** 赤く光るわくを子どもが自分で埋めます。正しければ次へ進み、まちがえても答えは見せません。
- **まちがいは責めない。** 出すのは「もういちど 考えて みよう」だけです。必要なら理由を短く言います（例：「4×3＝12で、10より 大きいよ」）。
- **最後はほめる。** 全部できたら花丸と紙ふぶきを出して、キャラがよろこびます。

## 2. 小さな支援を重ねる

大きな説明を1回するより、小さな手がかりをたくさん重ねます。どれも「見ればわかる」ものにします。

| 支援 | やり方 |
|---|---|
| ふりがな | 漢字には全部ふりがなをつける（`{漢字|かんじ}` と書けば ruby になる） |
| どこを見るか | 今使う数字を、半透明の黄色い蛍光ペンで光らせる |
| どこに書くか | 書くマスを赤いわくで光らせる |
| 何が起きたか | 自動で書くもの（くりあがり・くりさがり・補助の0）は、アニメーションと色で「今出た」ことを示す |
| 色の意味をそろえる | くりあがり＝オレンジ、くりさがり＝青、補助の0＝水色、10のまとまり＝緑、分ける数＝赤、矢印・計算の流れ＝黒、子どもが書いた数字＝紺 |
| いらなくなったもの | 消さずにななめ線を引く（くりさがり・いらない0・動かした小数点） |
| 数字の読み上げ | 数式は途中で改行しない（「2＋9」が行の境目で切れないようにする） |

## 3. 支援の段階（自分で選べる・あとから出る）

1. **ふつうの案内**：セリフと蛍光ペンと赤わく
2. **まちがえたとき**：「もういちど 考えて みよう」と、短い理由
3. **アシスト**：考え方そのものを図で見せる
   - くりあがり・くりさがり → さくらんぼ計算（実際の式の数でアニメーション）
   - かけ算・わり算 → その段の九九の表
   - 小数 → 小数点の場所、けたの数え方、小数点の動かし方、四捨五入、いらない0
   - 出し方の決まり：
     - 図のアシスト（さくらんぼなど）は「アシストを みる？」ボタンで出し、まちがえたときは自動で出す
     - 九九の表は、ボタンを押したときだけ出す（自動では出さない）
4. **すすむ**：本当にわからないときは、その一手の答えを見て先へ進める

## 4. ノート（マス目）のきまり

- **5mm方眼ノート風**。18列×13行。1マスに1文字。0行目は「式」の行。
- **ノートから絶対にはみ出さない。** そのため、けた数の上限は先に決める。
  - 例：たし算・ひき算は4けた、かけ算は4けた×3けた、わり算は4けた÷2けた
  - 上限を決めたら、自動テストで「はみ出さない・重ならない」ことを確かめる
- **教科書どおりの書き方**（日本の小学校）にする。
  - 位をそろえる
  - くりあがりは小さく書く（書く場所はせっていで選べる）
  - わり算は「たてる → かける → ひく → おろす」
  - いちばん左の0は書かない
- 小数点はマスを使わず、数字の右下の線の上に打つ。
- ノートの「マス」と「線」を、子どもが操作する場所としても使う（マスに書く、線をタップする、0をタップして消す）。

## 5. 画面（UI）のきまり

- **1600×900 の画面をまるごと縮小して表示する。** スクロールはしない。ページを変えるときは、逆転裁判のようにボタンで切り替える。
- **ボタンの大きさ・高さ・文字はそろえる。** ボタンはまなびバトル風のつやつやボタン（紺のふち、白い点、下に影）にする。
- **文字は UD デジタル 教科書体**（Windows に入っている）。
- **配置**：
  - 左：ノート
  - 右上：ふきだし（文字が多いときは自動で小さくして、はみ出さない）
  - 右下：キャラクターとテンキー
  - 上：もどす・すすむ・リセット・せってい
- **キャラクター**：まなびバトルの `all_cute_1`（左右を反転させて、ノートの方を向かせる）。正解でぴょんと跳ね、まちがいで首をふり、全部できたら大ジャンプする。
- **リセットは必ずポップアップで確認する。** 全部できたら、ノートの外に「つぎの 式を 入れる？」を出す。
- **効果音**：
  - 正解：ok
  - まちがい：ng
  - ボタン：btn
  - ポップアップ：pop
  - 入力：tap
  - 拍手：cheer
  - クリア：clear
  - せっていで、あり・なしを切り替えられる。

## 6. つかう場所と技術のきまり

- **子どもの端末**：Windows の Lenovo 11.6型、ブラウザは Edge（強制）。
- **学校のネットワーク**：渋谷区の i-フィルターで GitHub は開けないので、学校では Canva のホームページ版で配る。
- **1つの HTML ファイルで動く。** 画像も音も中に入れる（Canva 版は 10MB 以下）。外部への通信はしない。
- **配る版は2つ**：
  - **GitHub 版**：GitHub Pages で公開する。作者名は「K.nomura」。
  - **Canva 版**：`dist/*-canva.html`。作者名は「K.nomura」（どちらの版も同じ）。
- **セーブはしない**（その場で使うアプリ）。

## 7. 作り方のきまり

- **先に仕様を決める。** 「まだ実装しないで」と言われたら、案と質問を見せて待つ。
- **計算の手順（ロジック）と画面は分ける。**
  - ロジック（`logic*.js`）は、手順（ステップ）の一覧を作るだけにする。
  - 画面（`app.js`）は、その手順を順番に見せるだけにする。
- **手順（ステップ）の形**：
  - 種類：
    - `in`：マスに数字を入れる
    - `info`：説明だけ（「つぎへ」ボタンで進む）
    - `tap`：線（小数点の候補）をタップする
    - `zero`：マスをタップして消す
    - `choice`：ボタンで選ぶ
  - 中身：
    - `say`：セリフ
    - `hl`：光らせるマス
    - `box`：書くマス
    - `exp`：正しい答え
    - `pre`：その手順に入ったときに自動で書くもの
    - `add`：正解したときに書くもの
    - `assist`：アシストの種類
  - 「もどす」は、手順を1つ戻してノートをかき直すだけで実現する。
- **テスト**：
  - ロジックを何千問も自動で解かせて、答え・はみ出し・重なりを確かめる（`tools/*_test.js`）。
  - スクリーンショットで見た目を確かめる（`tools/shots*.py`、1366×650 で撮る）。
- **返事は短い日本語で。**

## 8. つかいまわせる部品（このリポジトリ）

| ファイル | 中身 |
|---|---|
| `src/style.css` | ノート、つやつやボタン、ふきだし、テンキー、アシストのポップアップ、モーダル、花丸、紙ふぶき |
| `src/app.js` | 画面の縮小、方眼の描画、手順の進め方、入力、もどす・すすむ、アシスト（さくらんぼ・九九・小数）、花丸、効果音 |
| `src/logic.js` / `src/logic-dec.js` | 筆算の手順づくり（たし・ひき・かけ・わり／小数） |
| `src/assets/` | キャラクター（chara.png）と効果音7つ |
| `tools/build.py` | 1ファイル化（GitHub 版と Canva 版を同時に作る） |
